DeepFlow

A Python framework for solving PDEs with Physics-Informed Neural Networks.

I wanted PINN experiments to feel less like stitching together training code and more like setting up a CFD problem.

DeepFlow is an open-source Python framework I built for fluid- and heat-flow problems. It uses a compact CFD-style workflow with GPU acceleration, making it possible to prototype simple 2D fluid-flow problems in under 30 lines of code.

Published research

Tracing light around a black hole

Numerical simulation and theoretical analysis of photon trajectories around a Schwarzschild black hole.

Before working on scientific machine learning, I spent time numerically studying how light moves around a black hole.

I developed the simulations and theoretical analysis used to categorize photon trajectories by their emission angles for a moving light source. The work became the paper The Photon Trajectories Around Black Hole with Moving Light Source, published in Journal of Physics: Conference Series, and was presented orally at the 18th Siam Physics Congress in 2023.

SPyH FluidSim

A lightweight 2D fluid simulator built from the SPH formulation upward.

I built SPyH to understand particle-based fluid simulation from the equations upward rather than treating the method as a black box.

I derived the Smoothed-Particle Hydrodynamics formulation in a five-page technical paper, then implemented it as a lightweight 2D simulator in Python using NumPy, SciPy, and Matplotlib.
